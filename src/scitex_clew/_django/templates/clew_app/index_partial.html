How to Use Clew

Forward: Track

Record inputs and outputs while running your analysis. Clew automatically records inputs, outputs, and hashes. 

import scitex
@scitex.session
def main():
    data = scitex.io.load("input.csv")
    scitex.io.save(result, "output.png")

Backward: Verify

Select any artifact to trace its full dependency chain back to source data as a DAG. 

scitex clew chain output.png
scitex clew status
scitex clew list

Click Add Examples to get started, then run bash ./examples/clew/00_run_all.sh from the project root.
